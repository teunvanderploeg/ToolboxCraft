ToolboxCraft 0.1.8 fixes an unexpected macOS dialog after installing or updating an app.

- Fixes the "Where is use_default?" application chooser shown when ToolboxCraft tries to display an app-ready notification.
- macOS notifications now use ToolboxCraft's application identity explicitly. If notification setup fails, ToolboxCraft skips the notification and logs the error.

ToolboxCraft 0.1.7 users receive this update automatically while the launcher is running, unless automatic ToolboxCraft updates are disabled in Settings. Users on 0.1.6 or earlier must install this release manually once.

Download the matching DMG, Windows setup EXE or portable ZIP, or Linux AppImage from the assets below. On macOS, quit ToolboxCraft and replace the copy in Applications. macOS builds use ad-hoc signing and Windows builds are unsigned, so initial installation can still show Gatekeeper or SmartScreen prompts.
