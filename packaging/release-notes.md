ToolboxCraft 0.1.9 makes app release notes easier to read with safe Markdown rendering.

- Release notes now display formatted headings, lists, emphasis, code, tables, and clickable web links.
- Link colors and emphasis work in both light and dark themes, and hovering over a link shows its destination.
- Links are limited to HTTP and HTTPS. HTML is displayed as inert text, and images show their alt text without loading remote, local, or embedded files.
- Empty release notes show a clear fallback message, and refreshed notes update immediately.

ToolboxCraft 0.1.7 and later receive this update automatically while the launcher is running, unless automatic ToolboxCraft updates are disabled in Settings. Users on 0.1.6 or earlier must install this release manually once.

Download the matching DMG, Windows setup EXE or portable ZIP, or Linux AppImage from the assets below. On macOS, quit ToolboxCraft and replace the copy in Applications. macOS builds use ad-hoc signing and Windows builds are unsigned, so initial installation can still show Gatekeeper or SmartScreen prompts.
