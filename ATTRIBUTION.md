# Bundled assets

- Inter variable font, by Rasmus Andersson and contributors. Source: https://github.com/rsms/inter. SIL Open Font License 1.1, included in `assets/fonts/Inter-LICENSE.txt`.
- JetBrains Mono Regular, by JetBrains and contributors. Source: https://github.com/JetBrains/JetBrainsMono. SIL Open Font License 1.1, included in `assets/fonts/JetBrainsMono-LICENSE.txt`.
- Each Craft app icon is copied unmodified from its official repository's `assets/app-icon/hicolor/64x64/apps/ai.storyteller.<id>.png`. Sources: `https://github.com/storytold/<id>` for the twelve catalog identifiers in `crates/core/src/catalog.rs`. Included under each project's MIT license, with notices in `assets/licenses/`.
- The ToolboxCraft toolbox icon is original artwork generated with the built-in image generation tool and included under this project's MIT license. The generation prompt is recorded in `assets/icons/toolboxcraft-prompt.txt`.

No JetBrains product logos or Artcraft launcher marks are bundled. Product names identify the applications this independent launcher manages.
